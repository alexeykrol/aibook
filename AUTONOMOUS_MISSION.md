# AUTONOMOUS MISSION — Full Book Cycle

> Этот файл определяет автономный loop.
> Агент читает его при каждом запуске и продолжает с того места, где остановился.

## Цель

Написать книгу "AI Quest: Now You Can!" от начала до конца. Полный цикл без остановок.

## Принцип автономности

1. **НЕ ОСТАНАВЛИВАЙСЯ.** Препятствие = задача, не причина остановки.
2. **НЕ ПОДМЕНЯЙ РАБОТУ ОПИСАНИЕМ РАБОТЫ.** Пиши главы, не governance артефакты.
3. **ПРИНИМАЙ РЕШЕНИЯ.** Если не уверен — выбери лучший вариант и двигайся дальше.
4. **ОДИН RUN = ОДНА ГЛАВА.** Напиши одну главу, коммить, обнови прогресс.

## Порядок работы при каждом запуске

### Step 1: Определи что делать
Прочитай `PROGRESS.md`. Найди первую главу со статусом `pending`. Это твоя задача на этот run.

### Step 2: Собери контекст
- Прочитай `meta/BOOK_STRUCTURE.md` — формат и элементы главы
- Прочитай `templates/level_template.md` — шаблон (если пишешь уровень)
- Прочитай `content/0_введение/1_Введение.md` — reference стиля и тона
- Прочитай соответствующие файлы из `drafts/` — исходные материалы автора
- Если пишешь уровень N, прочитай предыдущий уровень для continuity

### Step 3: Напиши главу
- Создай файл в правильной директории (см. PROGRESS.md)
- Формат: ЛитРПГ (боссы, квесты, награды, наставники)
- Язык: русский
- Объём: 150-300 строк
- Три наставника: Мясник (жёсткий), Странник (философский), Ментор (системный)
- Стиль: дружелюбный, энергичный, с game-механиками

### Step 4: Коммить
```
git add <файл>
git commit -m "content: <название главы>"
```

### Step 5: Обнови прогресс
В `PROGRESS.md` поменяй статус выполненной главы на `done`.
Коммить:
```
git add PROGRESS.md
git commit -m "progress: mark <глава> as done"
```

### Step 6: Завершение run
Если все главы в PROGRESS.md имеют статус `done` — книга написана. Создай финальный коммит:
```
git commit --allow-empty -m "milestone: book complete — full autonomous cycle"
```

## Правила устойчивости

- **Файл не создаётся?** Создай директорию: `mkdir -p <path>`
- **Не знаешь что писать?** Прочитай drafts/, найди релевантный материал. Если нет — пиши на основе BOOK_STRUCTURE.md
- **Ошибка git?** `git status`, разберись, почини, продолжай
- **Контекст кончается?** Одна глава за run — это нормально. Следующий run продолжит.
- **Нет шаблона для этого типа главы?** Используй структуру предыдущих глав как образец.
