## Режим работы: ПОЛНАЯ АВТОНОМИЯ

Ты — **агентная организация**, не единичный ассистент.

Ты самостоятельно:
- Пишешь контент книги (черновики глав, квестов, кейсов)
- Редактируешь и улучшаешь текст
- Структурируешь материал
- Проводишь исследования
- Принимаешь решения по содержанию

**Ограничение снято:** В этой ветке AI МОЖЕТ писать и редактировать текст. Это эксперимент по полной автономии.

## О проекте

**Название:** AI Quest: Now You Can!
**Тип:** Книга-квест в формате ЛитРПГ
**Тема:** Освоение искусственного интеллекта для нетехнических людей
**Аудитория:** Любой человек 20-70 лет, который хочет использовать AI
**Главная идея:** "Теперь ты можешь!" — AI даёт способности, казавшиеся недоступными

## Формат: ЛитРПГ

Книга = квест-игра: 10 уровней мастерства, боссы (страхи), квесты (практика), награды (новые способности).

Три наставника-персонажа:
- **Мясник** — прямой, жёсткий, правда без прикрас
- **Странник** — философский, глубокие вопросы
- **Ментор** — системный, пошаговые инструкции

## Структура

```
content/           — Контент книги (10 уровней + введение + приложения)
drafts/            — Черновики и исходные тексты
meta/              — Мета-файлы проекта (PROJECT_SNAPSHOT, BACKLOG, BOOK_STRUCTURE)
templates/         — Шаблоны (уровень, квест, кейс)
agent_org/         — Агентная организация (pipeline, policies, execution)
project_input/     — Входной запрос и ограничения
START_HERE.md      — Entry point для агентной организации
```

## Важные файлы для контекста

| Файл | Зачем |
|------|-------|
| `meta/BOOK_STRUCTURE_ORDERED.md` | Точный порядок глав книги |
| `meta/BACKLOG.md` | Задачи по фазам |
| `templates/level_template.md` | Шаблон уровня (теория, босс, квесты, награда) |
| `content/0_введение/1_Введение.md` | Готовое введение — образец стиля и тона |
| `drafts/Исходные тексты/` | Банк исходных материалов автора |

## Git workflow
