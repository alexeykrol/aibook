## О книге

**"Теперь ты можешь!"** — главная идея книги. С AI ты получаешь способности, которые раньше казались недоступными.

### Для кого эта книга?

- Для тех, у кого есть **амбиции и желание расти**
- Независимо от возраста, пола, профессии или образования
- Для тех, кто готов учиться и экспериментировать
- Для скептиков, которые хотят **проверить**, а не просто поверить

### Формат: ЛитРПГ

Книга построена как **квест-игра** с 10 уровнями мастерства:

| Элемент | Описание |
|---------|----------|
| **Уровни** | 10 уровней от новичка до мастера AI |
| **Боссы** | Страхи и сомнения, которые нужно победить |
| **Квесты** | Практические задания для прокачки |
| **Награды** | Новые возможности после каждого уровня |

## Методология разработки

### Роман как код

Книга разрабатывается по принципам разработки ПО:

- **GitHub** — версионный контроль, защита main-ветки
- **VS Code** — редактор текста
- **Claude Code** — AI-агент как ассистент

### Роли: Автор vs AI

#### Автор (20% времени):
- Пишет текст
- Принимает творческие решения
- Редактирует художественную часть

**AI НЕ пишет и НЕ редактирует авторский текст!**

#### AI (80% времени):
- Анализ и структурирование
- Фактчекинг
- Исследования
- Контроль логики
- Управление структурой проекта

### Cold Start Protocol

Для эффективной работы после пауз используется **Cold Start Protocol**:

```
meta/PROJECT_SNAPSHOT.md  → Мгновенный обзор (~500 токенов)
meta/BACKLOG.md           → Задачи по фазам
meta/BOOK_STRUCTURE.md    → Структура книги
```

**Экономия:** 85% токенов = быстрее и дешевле!

## Как контрибьютить

Подробные инструкции — в [CONTRIBUTING.md](CONTRIBUTING.md)

### Быстрый старт для контрибьюторов

1. **Синхронизируйся** после паузы:
   ```bash
   /sync
   ```

2. **Прочитай** статус проекта:
   - `meta/PROJECT_SNAPSHOT.md` — что сейчас происходит
   - `meta/BACKLOG.md` — какие задачи доступны

3. **Создай ветку** для своей задачи:
   ```bash
   git checkout -b author/имя/описание-задачи
   ```

4. **Работай** над задачей, используя шаблоны из `templates/`

5. **Завершив работу**, скажи AI:
   ```bash
   /sprint-done
   ```

### Куда добавлять контент?

| Что хочешь добавить | Куда класть |
|---------------------|-------------|
| Новую главу уровня | `content/N_уровень_X/` |
| Упражнение (квест) | `content/N_уровень_X/exercises.md` |
| Кейс (пример) | `content/N_уровень_X/cases.md` |
| Идею для книги | `content/идеи/` |
| Заметки/исследования | `meta/notes/` |
