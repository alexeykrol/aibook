# First Run Protocol

Purpose: Bootstrap the agent organization for a new project.

## Prerequisites

Before the first run:
1. Ensure `project_input/PROJECT_REQUEST.md` is filled with the project description.
2. Optionally fill `project_input/PROJECT_CONSTRAINTS.md` with constraints.
3. Read `START_HERE.md` for the handoff sequence.

## First Run Checklist

- [ ] Read and understand `project_input/PROJECT_REQUEST.md`
- [ ] Evaluate: is the request clear enough to proceed?
  - If unclear → create `project_input/DISCOVERY_LOG.md` with questions
  - If clear → proceed
- [ ] Create a product brief in `agent_org/product/active_product_briefs/`
- [ ] Create an engineering spec in `agent_org/engineering/`
- [ ] Build task graph in `agent_org/execution/task_graph.md`
- [ ] Create work orders in `agent_org/execution/work_orders/`
- [ ] Update `agent_org/execution/status_board.md`
- [ ] Begin execution of the first work order
- [ ] Log handoff in `agent_org/execution/handoff_log.md`
- [ ] Write run summary
- [ ] Write evaluation trace
