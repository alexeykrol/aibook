# Mission

Build and operate an autonomous agent organization for **agent-org-test** that can accept, route, execute, and report on tasks from the project owner.

## Project

- **Name:** agent-org-test
- **Description:** TBD

## Core Objectives

1. **Intake:** Accept tasks via INBOX.md endpoint or project_input/ files.
2. **Self-routing:** Route tasks through product → engineering → execution pipeline.
3. **Execution:** Perform real work (code, research, design), not just governance artifacts.
4. **Quality gate:** Review results before delivery.
5. **Reporting:** Deliver concise summary to the project owner.

## Success Criteria

- Pipeline processes tasks end-to-end without human intervention for routine work.
- Organization produces real deliverables (code, reports, designs).
- Quality gate catches issues before delivery.
- Escalation triggers only for genuinely ambiguous or high-risk decisions.
