# Engineering Spec Template

Use this template when creating an engineering spec from a product brief.

## Fields

- **Spec ID:** ES-XXX
- **Product Brief:** Reference to PB-XXX
- **Technical Approach:** How will this be implemented?
- **Components Affected:** Which parts of the codebase are involved?
- **Dependencies:** External libraries, services, or prior tasks
- **Task Breakdown:**
  1. Task 1 — description
  2. Task 2 — description
  3. ...
- **Acceptance Criteria:** Technical criteria for completion
- **Risks:** What could go wrong?
- **Estimated Complexity:** Low / Medium / High
