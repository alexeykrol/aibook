# Artifact Change Policy

## Rules

- Pipeline artifacts (briefs, specs, work orders) should not be deleted after creation
- Major structure changes require a note in `knowledge/decision_log.md`
- Every update should be traceable to a task or work item

## Change Protocol

1. Document intent in `evolution/change_proposals.md` (for significant changes)
2. Update the relevant artifact
3. Record the change in `knowledge/decision_log.md`
