# Product Brief Template

Use this template when creating a new product brief for a task.

## Fields

- **Brief ID:** PB-XXX
- **Task:** Reference to the task from INBOX
- **Problem Statement:** What problem does this task solve?
- **Goal:** What is the desired outcome?
- **Scope:** What is included and excluded?
- **Constraints:** Technical, time, or resource constraints
- **Success Criteria:** How do we know the task is done?
- **Required Artifacts:** What deliverables are expected?
- **Handoff Target:** Who/what receives the output?
