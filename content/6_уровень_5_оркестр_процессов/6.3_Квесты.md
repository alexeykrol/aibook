## Квест 1: Первый Такт 🎵

**Навык:** Создание базового сценария из трёх модулей

**Легенда:** Каждый оркестр начинается с одной ноты. Один звук — и тишина сломана. Один работающий сценарий — и страх перед автоматизацией сломан навсегда.

**Задание:** Создай в Make сценарий из трёх модулей: триггер → AI-обработка → результат. Тема — любая. Цель — увидеть, как данные текут от модуля к модулю.

**Пошаговая инструкция:**

1. Открой Make → «Create a new scenario»
2. Добавь первый модуль: **Google Sheets → Watch New Rows** (или **Gmail → Watch Emails**, или **Webhook → Custom Webhook**)
3. Добавь второй модуль: **OpenAI (ChatGPT) → Create a Completion**. В промпте напиши: «Прочитай следующий текст и напиши краткое саммари в 2-3 предложения: {{текст из первого модуля}}»
4. Добавь третий модуль: **Google Sheets → Add a Row** (запиши результат в таблицу)
5. Нажми **Run once**
6. Посмотри, как зелёные галочки появляются на каждом модуле

**Если застрял — промпт-спасатель:**

```
Я новичок в Make (Integromat). Помоги мне создать
мой первый сценарий из трёх модулей:

1. Триггер: Google Sheets (новая строка в таблице)
2. Обработка: OpenAI (краткое саммари текста)
3. Результат: Google Sheets (запись в другую таблицу)

Объясни пошагово:
- Как подключить Google Sheets к Make
- Как настроить модуль OpenAI
- Как связать данные между модулями
- Как запустить и проверить

Я никогда не работал с Make.
Объясняй максимально просто.
```

**Критерий успеха:** Ты нажал «Run once» — и в таблице появилась строка, которую написал не ты, а твой сценарий. Три зелёных кружка. Данные прошли от начала до конца. Если это произошло — ты только что построил свой первый конвейер. Поздравляю. Серьёзно.

> **📋 Ментор:**
> «Первый сценарий всегда самый долгий. Подключение аккаунтов, настройка доступов, поиск нужных полей — это всё делается один раз. Второй сценарий займёт в три раза меньше времени. Третий — в десять раз. Не оценивай сложность Make по первому опыту. Это как судить о вождении по первому уроку в автошколе.»

## Квест 2: Умный Фильтр 🔍

**Навык:** Добавление логики и условий в сценарий

**Легенда:** Оркестр, играющий одну и ту же ноту на все случаи жизни, — не оркестр, а сигнализация. Настоящий дирижёр знает: на грустную мелодию — скрипки, на триумфальную — трубы. Твой сценарий тоже должен *различать*.

**Задание:** Возьми сценарий из Квеста 1 и добавь к нему условную логику: AI не просто обрабатывает данные — он *классифицирует* их, и сценарий *действует по-разному* в зависимости от результата.

**Пример: умная сортировка входящих запросов**

| Шаг | Модуль | Что делает |
|-----|--------|-----------|
| 1 | Gmail → Watch Emails | Ловит новое письмо |
| 2 | OpenAI → Create a Completion | «Определи категорию письма: СРОЧНОЕ, ОБЫЧНОЕ или СПАМ. Ответь одним словом.» |
| 3 | Router | Разветвление: три пути |
| 3a | → Если «СРОЧНОЕ» | Telegram → Send Message (уведомление тебе) |
| 3b | → Если «ОБЫЧНОЕ» | Google Sheets → Add Row (в таблицу на обработку) |
| 3c | → Если «СПАМ» | Ничего (или пометить прочитанным) |

**Ключевой элемент — Router:**
В Make есть модуль Router (разветвитель). Он берёт одни входные данные и направляет поток в разные ветки по условиям. Как стрелочник на железной дороге: этот поезд — на север, этот — на юг.

**Промпт для AI-классификатора:**

```
Ты — классификатор входящих писем.
Прочитай тему и тело письма.
Определи категорию:

- СРОЧНОЕ — требует ответа в течение 24 часов,
  содержит дедлайны, просьбы о помощи, жалобы
- ОБЫЧНОЕ — информационное, можно ответить
  в течение 2-3 дней
- СПАМ — рассылки, реклама, нерелевантное

Ответь ОДНИМ СЛОВОМ: СРОЧНОЕ, ОБЫЧНОЕ или СПАМ.
Никаких пояснений.
```

**Критерий успеха:** Сценарий *сам* решает, что делать с письмом. Срочное — ты получаешь уведомление в Telegram. Обычное — записывается в таблицу. Спам — игнорируется. Ты не принимал ни одного решения. AI принял его за тебя. Если ты почувствовал лёгкий холодок — «оно *думает* и *решает*?!» — значит, квест пройден.

> **🌀 Странник:**
> «До этого момента твои автоматизации были конвейерами — прямыми, как рельсы. Теперь ты добавил развилки. Конвейер стал *маршрутом*. Маршрут стал *решением*. А решение — это первый признак интеллекта. Твой сценарий больше не просто выполняет действия. Он *выбирает*, какие действия выполнить.»

## Квест 3: Контент-Конвейер 📱

**Навык:** Многошаговая AI-обработка с несколькими выходами

**Легенда:** Один бриллиант, огранённый по-разному, превращается в десять украшений. Одна идея, обработанная AI в нескольких форматах, превращается в контент для всех твоих платформ.

**Задание:** Построй сценарий, который берёт *одну* входную мысль и превращает её в контент для *нескольких* платформ одновременно.

**Схема сценария:**

```
[Ввод: текст мысли]
        ↓
   [AI: расширить]
        ↓
    ┌───┴───┐
    ↓       ↓
[AI: пост  [AI: пост
Telegram]   LinkedIn]
    ↓       ↓
[Отправить  [Сохранить
в Telegram]  в Sheets]
```

**Пошагово:**

1. **Триггер:** Google Sheets → Watch New Rows (ты добавляешь мысль в таблицу — одну строку, одну колонку)
2. **AI-расширитель:** OpenAI → «Вот короткая мысль: {{мысль}}. Расширь её до полноценного абзаца на 3-4 предложения. Сохрани авторский тон, не добавляй клише.»
3. **Router** — два пути:
4. **Путь A — Telegram-пост:** OpenAI → «Преобразуй этот текст в короткий пост для Telegram. Максимум 500 символов. Добавь один эмодзи в начале. Без хэштегов.» → Telegram → Send Message
5. **Путь B — LinkedIn-пост:** OpenAI → «Преобразуй этот текст в профессиональный пост для LinkedIn. 800-1200 символов. Начни с провокационного вопроса. Добавь 3 хэштега.» → Google Sheets → Add Row (в отдельную таблицу «LinkedIn-контент»)

**Критерий успеха:** Ты вписал одно предложение в таблицу — и через 30 секунд в Telegram появился пост, а в другой таблице — готовый текст для LinkedIn. Одна мысль → два готовых материала → ноль ручной работы. Если ты улыбнулся — квест пройден.

> **💀 Мясник:**
> «Знаешь, сколько людей тратят по два часа в день на создание контента? А ты только что построил машину, которая делает это за минуту. Не потому что ты гений. Потому что ты не побоялся соединить четыре кружочка в Make. Четыре кружочка — и два часа в день свободны. Математика проста.»

## Квест 4: Ночной Дозор 🌙

**Навык:** Автоматический режим + мониторинг + уведомления

**Легенда:** До сих пор ты нажимал «Run once» — как запускал ракету вручную. Пора отпустить руль. Пора включить автопилот и уйти спать, зная, что оркестр играет без тебя.

**Задание:** Возьми любой сценарий из предыдущих квестов (или создай новый) и переведи его в автоматический режим. Добавь модуль-отчёт, который присылает тебе итоги работы.

**Три шага к автопилоту:**

**Шаг 1: Добавь предохранитель.**
В конец сценария добавь модуль Telegram → Send Message с отчётом:
```
📊 Отчёт сценария:
Время: {{now}}
Обработано: {{данные}}
Статус: Успешно
```

**Шаг 2: Включи расписание.**
Внизу сценария переключи Scheduling с OFF на ON. Выбери интервал: каждые 15 минут, каждый час или при каждом новом событии. Начни с «каждый час» — так спокойнее.

**Шаг 3: Уйди.**
Серьёзно. Закрой вкладку. Займись другим. Подожди час. Проверь Telegram — там будет отчёт. Проверь таблицу — там будут новые строки. Всё произошло *без тебя*.

**Промпт для AI-анализатора с порогом уверенности:**

```
Ты — аналитик входящих данных.
Проанализируй следующий текст: {{текст}}

Ответь в формате JSON:
{
  "категория": "тип данных",
  "саммари": "краткое описание",
  "уверенность": число от 0 до 100,
  "требует_внимания": true/false
}

Если уверенность ниже 70 — установи
"требует_внимания": true.
```

Добавь фильтр после AI-модуля: если `требует_внимания = true` → отправь в Telegram с пометкой «⚠️ Требует проверки». Это твоя страховка. AI, который не уверен — зовёт человека.

**Критерий успеха:** Ты ушёл от компьютера минимум на час. Вернулся — и в Telegram лежат отчёты о работе сценария. Таблицы обновлены. Что-то произошло *без тебя*. Если ты почувствовал странную смесь восторга и тревоги — «оно работает, пока меня нет!» — поздравляю. Ты стал дирижёром.

> **🌀 Странник:**
> «Первая ночь, когда твой сценарий работал без тебя — это момент трансформации. Как первая ночь, когда ребёнок спал один. Ты не спишь, проверяешь, волнуешься. Но утром видишь: всё в порядке. И на вторую ночь ты уже спокойнее. На третью — ты даже не думаешь об этом. Это не лень. Это доверие. Доверие к системе, которую ты сам построил.»

## Квест 5: Полный Оркестр 🎼

**Навык:** Комплексный многошаговый сценарий с AI-принятием решений

**Легенда:** Первый такт, фильтр, конвейер, ночной дозор — это были отдельные инструменты. Теперь ты соберёшь полный оркестр. Один сценарий, который решает *реальную* задачу от начала до конца. Не учебную. Не игрушечную. Настоящую.

**Задание:** Построй сценарий, который автоматизирует один из *твоих* реальных процессов. Целиком. От триггера до финального действия. С AI на борту.

**Три варианта (выбери свой или придумай):**

### Вариант A: Умный Почтовый Помощник
```
Новое письмо → AI читает и классифицирует →
→ Срочное: уведомление в Telegram + черновик ответа
→ Обычное: саммари в таблицу
→ Спам: пометить прочитанным
→ Отчёт в конце: «За день обработано X писем»
```

### Вариант B: Персональный Новостной Дайджест
```
Каждое утро (по расписанию) →
→ AI получает RSS-ленты / заголовки из 3 источников →
→ AI фильтрует по твоим интересам →
→ AI пишет краткий дайджест на 5-7 пунктов →
→ Дайджест летит в Telegram →
→ Полная версия сохраняется в Google Docs
```

### Вариант C: Трекер Задач с AI-мозгом
```
Новая задача в Google Sheets →
→ AI оценивает: приоритет, сложность, время →
→ AI предлагает порядок выполнения →
→ Если срочная — уведомление в Telegram
→ Еженедельно — AI пишет отчёт: что сделано, что зависло
```

**Не знаешь, с чего начать? Вот промпт:**

```
Я хочу автоматизировать следующий процесс:
[опиши процесс своими словами]

Я использую Make (Integromat). Мне доступны:
Gmail, Google Sheets, OpenAI, Telegram, Webhook.

Помоги мне спроектировать сценарий:
1. Какие модули мне нужны и в каком порядке
2. Что написать в промпте для AI-модуля
3. Где добавить Router (если нужно)
4. Какое расписание поставить
5. Какие предохранители добавить

Я умею строить простые сценарии из 3-4 модулей.
Объясняй как наставник, но не как для новичка.
```

**Критерий успеха:** У тебя есть работающий сценарий из 5+ модулей, который решает *твою* задачу. Он включён в автоматический режим. Он работает, пока ты не работаешь. Ты — дирижёр оркестра, а не музыкант, дующий в трубу.

> **📋 Ментор:**
> «Когда построишь полный сценарий — запиши три вещи. Первое: сколько времени ты тратил на этот процесс вручную каждую неделю. Второе: сколько тратишь теперь (скорее всего — ноль). Третье: что ты делаешь в освободившееся время. Эти три числа — лучшее доказательство того, что пятый уровень пройден. Не для кого-то. Для себя.»
