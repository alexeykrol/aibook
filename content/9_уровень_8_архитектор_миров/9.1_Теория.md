Архитектор Миров — про другое.

Здесь ты не создаёшь инструменты. Здесь ты создаёшь **агентов**. Автономные системы, которые не просто выполняют команды — они ставят цели, планируют шаги, используют инструменты и доводят задачи до конца без твоего участия.

Разница огромная.

Калькулятор делает то, что ты нажал. Агент делает то, что ты **описал** — сам, шаг за шагом, корректируя путь.

Раньше создать автономного агента — это был многомесячный проект для команды инженеров. Системы машинного обучения, обработка текста, архитектура принятия решений. Это был мир, где доступ к «думающим» системам имели только корпорации.

Теперь ты можешь запустить рабочего агента за один вечер.

- [ ] Навык настройки агентов через MCP — подключение инструментов и данных

## Главный враг этого уровня: Архитектор-Скептик

Бос этого уровня живёт в голове, и у него убедительный голос.

> *«Агенты — это фантастика. Я видел демо — они постоянно ошибаются, зависают, несут чушь. Это не работает в реальной жизни.»*

Он не полностью неправ. Агенты 2022-2023 годов действительно были ненадёжны. Они петляли, теряли контекст, делали дорогостоящие ошибки.

Агенты 2025-2026 — это другие системы.

Модели стали точнее. Инструменты для создания агентов — зрелее. Сообщество накопило паттерны и лучшие практики. И самое главное: ты больше не пишешь агент с нуля — ты **настраиваешь** то, что уже работает.

**Второй барьер:** *«Для этого точно нужно программирование»*

Нет. Для простых агентов достаточно описания на русском языке. Для сложных — минимальный JSON и конфигурационные файлы, которые AI объяснит и напишет за тебя.

**Как победить:** Запусти первого агента прежде, чем решишь, работает это или нет. Пять минут — и у тебя будет живой пример, а не теория.

## Что такое AI-агент

Слово «агент» перегружено. Давай определим точно.

**Обычный чатбот:** ты спрашиваешь → он отвечает → конец. Одна итерация, один ответ.

**AI-агент:** ты ставишь задачу → он планирует шаги → выполняет их по очереди → использует инструменты (поиск, файлы, браузер, API) → проверяет результат → корректирует → докладывает итог.

Ключевое отличие — **цикл обратной связи** и **доступ к инструментам**.

Агент не просто генерирует текст. Он действует в среде.

### Анатомия агента

Любой агент состоит из четырёх элементов:

**1. Модель (мозг)**
Языковая модель — Claude, GPT-4o, Gemini, Llama. Она принимает решения, интерпретирует ситуацию, формирует следующие шаги.

**2. Инструменты (руки)**
То, что агент может делать: поиск в интернете, чтение файлов, отправка email, выполнение кода, вызов API, работа с браузером. Каждый инструмент — отдельная способность.

**3. Память (контекст)**
Что агент помнит о задаче: предыдущие шаги, промежуточные результаты, ограничения. Без памяти агент не может строить сложные цепочки действий.

**4. Цикл (петля)**
Механизм повторения: делай шаг → оцени результат → реши что дальше → делай следующий шаг. Агент работает в этой петле до завершения задачи.

## MCP: язык агентов

MCP расшифровывается как **Model Context Protocol** — открытый стандарт, который создала компания Anthropic.

Представь, что у тебя есть умный помощник, но он заперт в комнате без окон. Он может думать, но не может ничего делать. MCP — это протокол, который открывает окна и двери: подключает к помощнику инструменты, данные, сервисы.

**Что MCP позволяет:**

| MCP-сервер | Что даёт агенту |
|------------|-----------------|
| `filesystem` | Читать и писать файлы на твоём компьютере |
| `browser` | Открывать сайты, заполнять формы, кликать |
| `github` | Читать репозитории, создавать задачи |
| `slack` | Отправлять сообщения, читать каналы |
| `postgres` | Запрашивать и обновлять базу данных |
| `google-maps` | Искать места, строить маршруты |
| `fetch` | Делать HTTP-запросы к любому API |

Каждый MCP-сервер — это набор инструментов, которые агент получает автоматически.

**Как это выглядит на практике:**

Ты настроил Claude Desktop с MCP-сервером `filesystem`. Теперь ты говоришь:

> *«Просмотри папку Downloads, найди все PDF-файлы за прошлый месяц, извлеки из каждого ключевые данные и создай сводную таблицу в Excel»*

Claude не просто отвечает — он открывает папку, читает файлы один за другим, извлекает данные, создаёт файл. Автономно.

Это и есть агент с MCP.

## Типы агентов по сложности

### Уровень 1: Агент-исполнитель

Простейший агент. Одна задача, линейная цепочка шагов, фиксированные инструменты.

**Пример:** Агент мониторинга конкурентов. Каждый день: открывает сайты конкурентов → читает новости и изменения → сравнивает с предыдущей версией → отправляет тебе краткую сводку в Telegram.

**Инструменты:** браузер, поиск, Telegram API
**Автономность:** полная, без участия человека
**Создание:** настройка через Claude Desktop + MCP, без кода

---

### Уровень 2: Агент-аналитик

Агент с разветвлённой логикой. Получает задачу → исследует → принимает решения в зависимости от того, что нашёл.

**Пример:** Агент исследования рынка. Ты говоришь: «Хочу открыть кофейню в Москве, найди мне три района с наибольшим потенциалом». Агент: ищет данные о трафике → анализирует конкуренцию → проверяет аренду → сравнивает демографию → строит рейтинг с обоснованием.

**Инструменты:** поиск, карты, браузер, данные
**Автономность:** высокая, но с финальным отчётом тебе
**Создание:** LangChain, CrewAI, или Claude Projects с инструкциями

---

### Уровень 3: Многоагентная система

Несколько агентов, каждый со своей специализацией. Один координирует, другие выполняют, результаты собираются воедино.

**Пример:** Система создания контента. Агент-редактор получает тему → Агент-исследователь находит материал → Агент-автор пишет черновик → Агент-критик проверяет и правит → Агент-публикатор размещает в блоге и соцсетях.

**Инструменты:** поиск, файлы, API соцсетей, браузер
**Автономность:** максимальная — ты ставишь задачу утром, к вечеру получаешь опубликованный материал
**Создание:** CrewAI, AutoGen, LangGraph

## Инструменты для создания агентов

### Claude Desktop + MCP-серверы

Самый простой старт. Claude Desktop — это приложение от Anthropic. В него встроена поддержка MCP.

**Что нужно:**
1. Скачать Claude Desktop (desktop.claude.ai)
2. Добавить конфигурацию MCP-серверов в JSON-файл
3. Перезапустить приложение
4. Работать с Claude как обычно — но теперь у него есть инструменты

**Пример конфигурации:**
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/ты/Documents"]
    }
  }
}
```

Этот JSON даёт Claude доступ к твоей папке Documents. Три строки — и агент читает и пишет твои файлы.

**Для кого:** Для начинающих. Без программирования. Максимум — скопировать JSON из документации.

---

### CrewAI

Фреймворк для многоагентных систем. Ты описываешь команду агентов: кто они, какая у каждого роль, какие инструменты, как они взаимодействуют.

**Концепция:** Crew (команда) → Agents (участники) → Tasks (задачи) → Tools (инструменты)

**Пример описания агента:**
```python
researcher = Agent(
  role='Senior Researcher',
  goal='Find the best AI tools for small businesses',
  backstory='Expert in AI tools with 10 years of experience',
  tools=[search_tool, browser_tool]
)
```

Читай это как описание сотрудника, а не как программирование. Роль, цель, контекст, инструменты.

**Для кого:** Для тех, кто готов к минимальному Python. Cursor напишет всё за тебя — ты только объяснишь задачу.

---

### n8n с AI-агентами

n8n — визуальный инструмент автоматизации (как Make), но с поддержкой AI-агентов. Ты строишь агента через интерфейс: перетаскиваешь блоки, соединяешь их, настраиваешь через формы.

**Для кого:** Для тех, кто уже знаком с Make и хочет добавить агентную логику без кода.

---

### AutoGPT и OpenDevin

Автономные агенты с браузером, файловой системой, выполнением кода. Ставишь задачу в текстовом поле — агент работает сам, показывает каждый шаг, спрашивает подтверждения в критических точках.

**Для кого:** Для экспериментов. Мощные, но требуют надзора.

## Принцип Архитектора: Описывай → Делегируй → Контролируй

Агенты меняют отношение к задачам. Раньше ты делал шаги сам. Теперь ты **описываешь результат** и **делегируешь выполнение**.

Это требует другого мышления.

**Хорошее описание задачи для агента:**

> *«Каждое утро в 8:00: открой мою почту, найди все письма с пометкой "срочно", составь список задач по приоритету, отправь мне в Telegram. Если письмо от клиента Иванова — отвечай автоматически: "Получил, свяжусь в течение дня"»*

**Плохое описание:**

> *«Разберись с почтой»*

Агент — не волшебник. Он так же зависит от качества твоих инструкций, как и обычный AI. Чем точнее ты описываешь ожидаемое поведение, тем надёжнее результат.

**Контроль — не слабость**

Хорошая агентная система включает checkpoints: точки, где агент останавливается и спрашивает подтверждения перед важным действием (отправить email, удалить файл, сделать публикацию). Сначала — узкие разрешения. Потом, когда убедился что работает — расширяй автономность.

## Где агенты меняют реальные задачи

### Малый бизнес

**Проблема:** Владелец тратит два часа в день на рутинные задачи — мониторинг почты, ответы на типовые вопросы, сбор данных из разных источников.

**Агент:** Читает почту → классифицирует письма → отвечает на типовые автоматически → срочные помечает для личного внимания → собирает дневной дайджест.

**Результат:** Два часа превращаются в 15 минут просмотра дайджеста.

---

### Исследователи и аналитики

**Проблема:** Нужно отслеживать новые публикации по теме, собирать данные из нескольких источников, готовить еженедельный дайджест.

**Агент:** Каждый день просматривает заданные источники → извлекает релевантные материалы → категоризирует → пятничным вечером присылает структурированный отчёт.

**Результат:** Актуальная экспертиза без ежедневного сёрфинга.

---

### Предприниматели с онлайн-продуктами

**Проблема:** Мониторинг конкурентов, сбор обратной связи, анализ отзывов — задачи важные, но рутинные.

**Агент-команда:** Агент мониторинга + Агент анализа + Агент отчётности. Раз в неделю: полный анализ рынка, который раньше требовал дня работы маркетолога.

**Странник:**

## Ключевые идеи уровня

- AI-агент отличается от чатбота циклом обратной связи и доступом к инструментам — он действует, а не только отвечает.
- Агент состоит из четырёх элементов: модель, инструменты, память, цикл.
- MCP — открытый протокол, который подключает агентам реальные инструменты: файлы, браузер, API, базы данных.
- Три уровня сложности: агент-исполнитель, агент-аналитик, многоагентная система.
- Claude Desktop + MCP-серверы — самый простой старт без программирования.
- Принцип Архитектора: описывай результат точно → делегируй выполнение → контролируй через checkpoints.
