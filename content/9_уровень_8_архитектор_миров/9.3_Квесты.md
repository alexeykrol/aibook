## Квест 1: Первый Посланник 📜

**Навык:** Агентное целеполагание — постановка задачи вместо пошаговых вопросов

**Легенда:** Архитектор начинает с простого: один посланник, одна миссия. Ты не говоришь ему «поверни налево, потом направо, потом стучи в дверь». Ты говоришь: «Доставь послание королю и принеси ответ.» Как именно он дойдёт — его забота.

**Задание:** Поставь AI *цель* вместо пошагового вопроса — и получи комплексный результат.

**Пошаговая инструкция:**

1. Открой Claude (claude.ai) или ChatGPT
2. Выбери задачу из своей реальной жизни. Примеры:
   - Подготовить аналитику по теме для рабочего решения
   - Составить полный план события (день рождения, поездка, конференция)
   - Исследовать варианты покупки (техника, курсы, услуги)
   - Создать контент-стратегию для соцсетей

3. Напиши *целевой* промпт — не вопрос, а задание:

```
Ты — мой персональный аналитик.

Задача: мне нужно принять решение о [твоя ситуация].

Проведи полный анализ:
1. Собери ключевые факторы, влияющие на решение
2. Рассмотри минимум 3 варианта с плюсами и минусами каждого
3. Оцени каждый вариант по критериям: стоимость, время, риски, выгода
4. Сведи результаты в таблицу для сравнения
5. Дай рекомендацию с обоснованием

Формат: структурированный отчёт, который можно показать коллеге или партнёру.
```

4. Получи результат. Оцени: ты задал *одну* задачу — а получил исследование, которое вручную заняло бы час.
5. Теперь дай обратную связь: *«Добавь ещё один вариант: [какой]. И пересчитай рейтинги с учётом того, что для меня [приоритет] важнее всего»*.
6. Заметь разницу: ты не диктуешь каждый шаг. Ты *корректируешь курс*.

**Критерий успеха:** Ты получил комплексный результат, на который вручную ушло бы более часа. Ты ставил цель, а не задавал десять вопросов по очереди. Ты почувствовал разницу между «собеседник» и «исполнитель миссии».

> **📋 Ментор:**
> «Ключ к первому квесту — перестать думать "что спросить у AI" и начать думать "что поручить AI". Вопрос получает ответ. Поручение получает результат. Архитектор не задаёт вопросы — архитектор ставит задачи.»

## Квест 2: Агент с Памятью 🧠

**Навык:** Создание персонализированного агента с контекстом в Claude Projects или Custom GPT

**Легенда:** Первый посланник выполнил миссию — но забыл тебя на следующий день. Теперь ты создаёшь агента, который *помнит*. Который знает, кто ты, чем занимаешься, что для тебя важно. Агент с памятью — это не просто инструмент. Это сотрудник, который с каждой задачей становится полезнее.

**Задание:** Создай проект в Claude Projects (или Custom GPT в ChatGPT) — персонального агента для своей реальной деятельности.

**Пошаговая инструкция:**

1. Открой Claude → Projects → «New Project»
2. Напиши системную инструкцию для агента:

```
Ты — мой персональный [роль: бизнес-ассистент / контент-менеджер /
исследовательский помощник / карьерный советник].

Обо мне:
- Я занимаюсь [чем ты занимаешься]
- Мои главные задачи: [перечисли 3-5 задач]
- Мой стиль общения: [формальный / неформальный / деловой]
- Мне важно: [приоритеты]

Твои правила:
1. Всегда учитывай мой контекст при ответах
2. Предлагай решения, а не просто информацию
3. Если видишь проблему в моём подходе — скажи прямо
4. Форматируй ответы структурировано: заголовки, списки, таблицы
5. В конце каждого ответа предлагай следующий шаг
```

3. Загрузи контекст — 2-3 документа, связанных с твоей деятельностью (план, заметки, данные о клиентах, расписание)
4. Задай агенту пять разных задач. Наблюдай, как он использует *твой* контекст
5. После пятой задачи напиши: *«На основе всех наших задач и моего контекста — какие ещё задачи ты мог бы для меня выполнять? Предложи 5 идей, о которых я не подумал»*

**Критерий успеха:** У тебя есть агент, который знает, кто ты. Который использует загруженный контекст для более точных ответов. Который предлагает идеи, на которые *ты сам* не вышел бы. Ты чувствуешь: это уже не чат. Это помощник.

> **🌀 Странник:**
> «Память — вот что превращает инструмент в спутника. Молоток не помнит, что вчера ты забивал гвоздь. Ассистент — помнит. И когда ты говоришь "сделай как в прошлый раз, но с учётом нового клиента" — он понимает. Ты только что создал существо, у которого есть прошлое. А значит — и способность к росту.»

## Квест 3: Конвейер Смыслов 🔄

**Навык:** Цепочка агентных задач — один результат становится входом для следующего

**Легенда:** Один агент — хорошо. Но настоящий архитектор строит *процессы*. Конвейер, где каждый шаг подпитывает следующий. Исследователь находит — аналитик обрабатывает — писатель оформляет. Ты — дирижёр. Оркестр играет сам.

**Задание:** Создай цепочку из трёх агентных задач, где результат первой — вход для второй, а результат второй — вход для третьей.

**Пошаговая инструкция:**

1. Выбери реальный сценарий. Примеры:
   - **Контент-конвейер:** Исследование темы → Создание статьи → Адаптация для соцсетей
   - **Бизнес-аналитика:** Сбор данных о конкурентах → Анализ и сравнение → Стратегические рекомендации
   - **Обучение:** Поиск материалов по теме → Конспект ключевых идей → Тест для проверки знаний
   - **Планирование:** Сбор вариантов → Сравнительный анализ → Финальный план действий

2. Выполни шаг 1 — дай агенту первую целевую задачу:

```
Шаг 1: Исследование.

Найди 7-10 ключевых трендов в [твоя тема] за последние 6 месяцев.
Для каждого тренда:
- Название и суть (2-3 предложения)
- Почему это важно
- Пример или источник
Результат оформи в виде структурированного отчёта.
```

3. Скопируй результат. Выполни шаг 2 — используй его как вход:

```
Шаг 2: Анализ.

Вот результаты исследования: [вставь результат шага 1]

На основе этих данных:
1. Выдели 3 самых перспективных тренда для [твоя ситуация]
2. Для каждого дай оценку: сложность внедрения, потенциальная выгода, срок окупаемости
3. Сведи в таблицу с рейтингом от 1 до 10
4. Рекомендуй один тренд для старта — и объясни почему
```

4. Скопируй результат. Выполни шаг 3:

```
Шаг 3: План действий.

Вот анализ трендов и рекомендация: [вставь результат шага 2]

Создай пошаговый план внедрения рекомендованного тренда:
- 5 конкретных шагов
- Для каждого шага: что делать, сколько времени, какие ресурсы нужны
- Ожидаемый результат через 1 месяц, 3 месяца, 6 месяцев
- Риски и как их минимизировать
```

5. Посмотри на финальный результат. За три шага ты прошёл путь от «у меня нет информации» до «у меня есть план действий».

**Критерий успеха:** Ты провёл цепочку из трёх агентных задач. Каждый шаг опирался на результат предыдущего. Финальный результат — план или документ, готовый к действию. Ты понимаешь: конвейер — это не три отдельных вопроса. Это *процесс*, который превращает сырые данные в решения.

> **💀 Мясник:**
> «Три шага. Полчаса. И у тебя исследование, анализ и план действий. Знаешь, сколько это стоит у консалтинговой фирмы? Не знаешь — и не надо. Ты только что сделал работу, за которую компании платят тысячи долларов. Бесплатно. За тридцать минут. И если ты после этого скажешь "мне не нужны агенты" — я сдаюсь.»

## Квест 4: Команда Специалистов 👥

**Навык:** Мульти-ролевая работа — несколько агентов с разными специализациями

**Легенда:** В Квесте 3 ты был конвейером. Теперь ты — командир отряда. У тебя есть Исследователь, Критик и Стратег. Каждый видит задачу со своей стороны. Вместе они дают результат, который ни один из них не дал бы в одиночку.

**Задание:** Создай трёх «специалистов» в разных чатах (или с разными системными промптами) и используй их для решения одной задачи.

**Пошаговая инструкция:**

1. Выбери задачу, которая требует разных точек зрения. Примеры:
   - Запуск нового продукта/проекта
   - Решение сложной жизненной ситуации (смена работы, переезд, инвестиции)
   - Разработка стратегии для бизнеса или карьеры
   - Создание сложного документа (бизнес-план, предложение, презентация)

2. Создай трёх агентов:

**Агент 1: Визионер**
```
Ты — Визионер. Креативный стратег с безграничным оптимизмом.
Твоя задача: видеть возможности там, где другие видят препятствия.
Ты всегда думаешь масштабно, предлагаешь смелые идеи,
вдохновляешь на амбициозные цели.
При анализе задач фокусируйся на потенциале и возможностях.
```

**Агент 2: Критик**
```
Ты — Критик. Жёсткий аналитик, который ищет слабые места.
Твоя задача: находить проблемы, риски, недостатки в любой идее.
Ты не цинник — ты реалист, который защищает от ошибок.
Задавай неудобные вопросы. Указывай на то, что может пойти не так.
Каждый риск оцени по шкале: вероятность и последствия.
```

**Агент 3: Стратег**
```
Ты — Стратег. Прагматичный планировщик, который синтезирует идеи.
Тебе дают мнение оптимиста и критику скептика.
Твоя задача: найти золотую середину.
Создай реалистичный план, учитывающий и возможности, и риски.
Каждый пункт плана должен отвечать на «что делать», «когда» и «зачем».
```

3. Дай Визионеру свою задачу. Получи его анализ.
4. Скопируй задачу И ответ Визионера → отправь Критику: *«Вот задача и предложение коллеги. Найди слабые места.»*
5. Скопируй оба ответа → отправь Стратегу: *«Вот мнения двух экспертов. Создай финальный план.»*
6. Прочти финальный план. Он будет глубже, чем любой из трёх ответов по отдельности.

**Критерий успеха:** Ты получил три разных взгляда на одну задачу. Финальный план Стратега учёл и амбиции Визионера, и риски Критика. Ты понял: *разнообразие перспектив* — мощнее единственного мнения. И что тебе не нужна реальная команда, чтобы получить командный результат.

> **📋 Ментор:**
> «Секрет этого квеста — в правильных ролях. Не делай трёх одинаковых "помощников". Делай конфликтующие роли: оптимист и скептик, мечтатель и прагматик, стратег и тактик. Именно в столкновении разных перспектив рождается качество. Как в реальной команде — если все согласны, значит кто-то не думает.»

## Квест 5: Автономный Архитектор 🏛️

**Навык:** Создание полностью автономного агента для повторяющейся задачи

**Легенда:** Финальный квест. Ты создаёшь агента, которого можно «запустить и забыть». Не на один раз — на постоянное использование. Агент с памятью, с контекстом, с чёткой инструкцией. Твой первый цифровой сотрудник, который выходит на работу каждый день.

**Задание:** Создай полноценного агента в Claude Projects (или Custom GPT), который решает твою повторяющуюся задачу — с инструкцией, контекстом и протоколом работы.

**Пошаговая инструкция:**

1. Определи задачу, которую ты выполняешь *регулярно* — каждый день, неделю или месяц:
   - Разбор и приоритизация входящих запросов
   - Подготовка еженедельных отчётов
   - Генерация идей для контента
   - Анализ обратной связи от клиентов
   - Подготовка к встречам или переговорам

2. Создай проект в Claude Projects с детальной инструкцией:

```
# Агент: [Название — например, «Недельный Стратег»]

## Кто ты
Ты — мой персональный [роль]. Ты работаешь на меня постоянно.

## Контекст обо мне
[3-5 предложений о тебе, твоей работе, приоритетах]

## Твоя основная задача
Каждый раз, когда я прихожу к тебе, ты:
1. [Первый шаг — что проверить/собрать]
2. [Второй шаг — что проанализировать]
3. [Третий шаг — что предложить]
4. [Четвёртый шаг — какой результат выдать]

## Формат результата
- Всегда начинай с краткого резюме (3 предложения максимум)
- Потом — детали в структурированном виде
- В конце — 3 рекомендованных действия с приоритетами

## Правила
- Не жди уточнений, если можешь сделать разумное предположение
- Если информации мало — скажи, что нужно, и предложи промежуточный результат
- Будь кратким, но не в ущерб содержанию
- Предлагай то, о чём я не подумал
```

3. Загрузи 3-5 релевантных документов в качестве контекста
4. Протестируй агента: дай ему задачу так, будто это рабочее утро понедельника. Оцени результат.
5. Улучши инструкцию: что он сделал не так? Добавь правило или пример.
6. Протестируй ещё раз. Повтори, пока результат не станет таким, что ты скажешь: *«Это реально экономит мне время»*.
7. **Бонус:** Используй этого агента в следующие 7 дней для реальной задачи. Каждый раз дорабатывай инструкцию на основе опыта.

**Если застрял — промпт-спасатель:**

```
Помоги мне создать персонального AI-агента для постоянного использования.

Моя ситуация:
- Я [кто ты, чем занимаешься]
- Каждую [неделю/день] я трачу время на [задача]
- Это занимает примерно [сколько времени]

Создай для меня:
1. Системную инструкцию для этого агента
2. Список документов, которые стоит загрузить в контекст
3. Три тестовых задачи для проверки
```

**Критерий успеха:** У тебя есть агент с детальной инструкцией и загруженным контекстом. Ты протестировал его минимум дважды и улучшил инструкцию. Результат его работы реально полезен — не «интересен», а *полезен*. Ты готов использовать его завтра. И послезавтра.

> **🌀 Странник:**
> «Ты только что перешёл грань. По одну сторону — человек, который использует AI, когда вспомнит. По другую — человек, у которого есть цифровой сотрудник, работающий на него постоянно. Первый тратит время. Второй инвестирует однажды — и собирает дивиденды каждый день. Какую сторону выбираешь ты?»
