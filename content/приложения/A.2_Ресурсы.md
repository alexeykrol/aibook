## Как пользоваться этим разделом

Ресурсы организованы по уровням Квеста. Для каждого уровня:
- **🔗 Основные инструменты** — сервисы, которые нужны прямо сейчас
- **📖 Для углублённого изучения** — статьи, курсы, каналы
- **⚡ Лайфхак Квестора** — один совет, который сэкономит часы

Начни с того уровня, на котором находишься. Не пытайся охватить всё сразу — это ловушка.

> **💀 Мясник:**
> «Знаешь, как гибнут новички? Они открывают список из 200 ресурсов и пытаются изучить каждый. Через два дня — паралич. Через неделю — выгорание. Через месяц — "AI — это не моё". Выбери ОДИН инструмент на уровень. Освой. Двигайся дальше. Остальное — потом.»

> **📋 Ментор:**
> «Автоматизация — это не "один раз настроил и забыл". Это итерационный процесс. Начни с простейшего сценария: триггер → действие. Убедись, что работает. Потом добавь шаг. Потом ещё один. Сложные системы строятся из простых блоков.»

### ⚡ Лайфхак Квестора

> Перед автоматизацией запиши процесс вручную: «Когда происходит X → я делаю Y → результат Z». Если не можешь описать словами — не сможешь автоматизировать.

> **💀 Мясник:**
> «Агенты — это не игрушка. Это оружие. Неправильно настроенный агент сожрёт твой бюджет API за час, разошлёт мусорные письма или удалит нужные файлы. Начинай с песочницы. Всегда. Без исключений.»

### ⚡ Лайфхак Квестора

> Правило «трёх стен»: каждый агент должен иметь лимит бюджета, лимит действий и лимит времени. Три стены, за которые он не может выйти. Настрой их ДО запуска.

## ⚠️ Важное предупреждение

> **📋 Ментор:**
> «Мир AI движется со скоростью света. Ссылки могут устаревать. Сервисы — закрываться или менять условия. Но принцип остаётся: ищи лучший инструмент для своей задачи, осваивай его, двигайся к следующему уровню. Конкретные ссылки — это указатели на карте. Карта может меняться. Но умение читать карту — навык вечный.»

Если ссылка не работает — используй AI, чтобы найти актуальную альтернативу. Ты уже умеешь это делать. В этом и есть суть Квеста.
