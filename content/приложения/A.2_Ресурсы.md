# Приложение A.2 — Ресурсы и инструменты

> *«Инструмент не делает мастера. Но мастер без инструмента — просто человек с хорошими намерениями.»*
> **— Мясник**

Здесь собраны все ИИ-инструменты и ресурсы, упомянутые в книге. Каждый — с коротким описанием и указанием, когда его использовать. Не нужно пробовать всё сразу. Начни с одного инструмента на каждом уровне — остальные придут по мере роста.

## Универсальные ИИ-ассистенты

Это твои главные инструменты. С них начинается квест.

### ChatGPT
**Кто:** OpenAI
**Сайт:** chat.openai.com
**Для чего:** Универсальный ассистент — текст, код, анализ, изображения (DALL·E), голос, веб-поиск. Самый известный ИИ в мире.
**Тарифы:** Бесплатный план (GPT-4o mini) / Plus $20/мес (GPT-4o, GPT-o1) / Pro $200/мес
**Лучше всего:** Для ежедневных задач, создания кастомных GPT, работы с документами
**Первый уровень:** Уровень 1 — Врата Джина

### Claude
**Кто:** Anthropic
**Сайт:** claude.ai
**Для чего:** Работа с длинными текстами, анализ документов, сложные рассуждения, написание и редактура.
**Тарифы:** Бесплатный план / Pro $20/мес (Claude Sonnet/Opus)
**Лучше всего:** Длинные документы, нюансированный анализ, следование сложным инструкциям
**Первый уровень:** Уровень 1 — Врата Джина

### Gemini
**Кто:** Google
**Сайт:** gemini.google.com
**Для чего:** Интеграция с экосистемой Google: Gmail, Docs, Drive, Sheets. Поиск актуальной информации.
**Тарифы:** Бесплатный план / Advanced $20/мес (Gemini Ultra)
**Лучше всего:** Если работаешь в Google Workspace, нужна свежая информация из интернета
**Первый уровень:** Уровень 1 — Врата Джина

### Perplexity
**Кто:** Perplexity AI
**Сайт:** perplexity.ai
**Для чего:** Поиск информации с проверкой источников и ссылками. ИИ, который всегда показывает, откуда взял данные.
**Тарифы:** Бесплатный / Pro $20/мес
**Лучше всего:** Исследования, фактчекинг, поиск актуальных данных
**Первый уровень:** Уровень 2 — Лабиринт Знаний

## Специализированные инструменты

### Генерация изображений

#### Midjourney
**Сайт:** midjourney.com
**Для чего:** Генерация художественных изображений высокого качества по текстовому описанию.
**Особенность:** Работает через Discord. Лучшее качество визуального арта среди всех генераторов.
**Тарифы:** От $10/мес (Basic) до $60/мес (Pro)
**Первый уровень:** Уровень 6 — Галерея Воображения

#### DALL·E 3
**Кто:** OpenAI (встроен в ChatGPT)
**Для чего:** Генерация изображений прямо из ChatGPT. Удобно — не нужно переключаться между сервисами.
**Тарифы:** Включён в ChatGPT Plus
**Первый уровень:** Уровень 6 — Галерея Воображения

#### Stable Diffusion
**Сайт:** stability.ai / Automatic1111 (локально)
**Для чего:** Открытая модель генерации изображений. Можно запускать локально без подписки.
**Особенность:** Максимальная гибкость и контроль для продвинутых пользователей. Бесплатно при запуске локально.
**Первый уровень:** Уровень 6 — Галерея Воображения

#### Leonardo AI
**Сайт:** leonardo.ai
**Для чего:** Генерация изображений с удобным веб-интерфейсом. Хорош для создания консистентных персонажей.
**Тарифы:** Бесплатный план (150 кредитов/день) / платные планы
**Первый уровень:** Уровень 6 — Галерея Воображения

### Код и разработка

#### GitHub Copilot
**Сайт:** github.com/features/copilot
**Для чего:** ИИ-ассистент для программистов. Дописывает код, объясняет функции, находит баги прямо в редакторе.
**Тарифы:** $10/мес (Individual) / бесплатно для студентов и open-source
**Первый уровень:** Уровень 7 — Кузница Создателя

#### Cursor
**Сайт:** cursor.sh
**Для чего:** Редактор кода с встроенным ИИ. Можно описать задачу на русском — ИИ напишет и изменит код. Идеален для нетехнических людей, делающих первые шаги в коде.
**Тарифы:** Бесплатный план / Pro $20/мес
**Первый уровень:** Уровень 7 — Кузница Создателя

#### Replit
**Сайт:** replit.com
**Для чего:** Онлайн-среда разработки с AI-ассистентом. Создаёшь и запускаешь код прямо в браузере. Не нужно ничего устанавливать.
**Тарифы:** Бесплатный план / Core $25/мес
**Первый уровень:** Уровень 7 — Кузница Создателя

## Автоматизация

### Make (бывший Integromat)
**Сайт:** make.com
**Для чего:** Визуальная автоматизация: соединяешь сервисы без кода. ИИ-интеграции, обработка данных, сложные сценарии.
**Тарифы:** Бесплатный (1000 операций/мес) / Core $9/мес
**Лучше всего:** Сложные многошаговые автоматизации с ИИ
**Первый уровень:** Уровень 5 — Оркестр Процессов

### Zapier
**Сайт:** zapier.com
**Для чего:** Классика автоматизации. Соединяет 6000+ сервисов. Проще чем Make, но менее гибкий.
**Тарифы:** Бесплатный (100 задач/мес) / Starter $20/мес
**Лучше всего:** Простые автоматизации «если X — то Y»
**Первый уровень:** Уровень 5 — Оркестр Процессов

### n8n
**Сайт:** n8n.io
**Для чего:** Открытая платформа автоматизации. Можно запускать локально (бесплатно). Максимальная гибкость для технически подготовленных.
**Тарифы:** Бесплатно (self-hosted) / Cloud от $20/мес
**Лучше всего:** Когда нужна гибкость и не хочешь платить за облако
**Первый уровень:** Уровень 5 — Оркестр Процессов

## Как выбирать инструменты

> *«Новичок хватается за всё. Мастер выбирает один инструмент и владеет им идеально.»*
> **— Мясник**

**Правило трёх инструментов:** На каждом этапе работай максимум с тремя инструментами одновременно. Освой их — потом расширяй арсенал.

**Стартовый набор (Уровень 1-3):**
- ChatGPT Plus или Claude Pro — главный ассистент
- Perplexity — когда нужны источники
- Gamma или Canva — для визуализации

**Рабочий набор (Уровень 4-6):**
- Добавь специализированный инструмент под твою сферу
- Make или Zapier — для автоматизации рутины
- Midjourney или DALL·E — для визуального контента

**Профессиональный набор (Уровень 7-10):**
- API доступ к моделям — прямое подключение
- Cursor или Replit — для создания инструментов
- Агентные платформы — для масштабирования
