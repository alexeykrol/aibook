# Приложение A.3 — Шаблоны промптов

> *«Хороший промпт — это не волшебное заклинание. Это чёткое техническое задание. Чем точнее ТЗ — тем меньше правок.»*
> **— Мясник**

Здесь — арсенал готовых шаблонов. Скопируй, замени текст в [квадратных скобках], отправь. Не изобретай велосипед каждый раз — используй проверенные конструкции.

Шаблоны сгруппированы по задачам. Начни с тех, что нужны прямо сейчас.

---

## Как пользоваться шаблонами

**Базовая структура промпта:**
```
Роль: Кто ты (эксперт, редактор, тренер)
Задача: Что именно нужно сделать
Контекст: Кто я, моя ситуация, детали
Формат: Как оформить ответ
Ограничения: Что нельзя делать
```

Не нужно использовать все блоки каждый раз. Начни с задачи — добавляй детали по мере надобности.

## Работа с текстом

### Написать текст с нуля

```
Напиши [тип текста: пост/статью/письмо] на тему «[тема]».

Аудитория: [кто будет читать — возраст, интересы, уровень знаний]
Тон: [формальный/дружелюбный/провокационный/экспертный]
Объём: [количество слов или абзацев]
Цель: [что должен сделать читатель после прочтения]

Включи: [конкретные элементы — факты, призыв к действию, примеры]
Избегай: [клише, сложных терминов, пассивного залога]
```

### Улучшить готовый текст

```
Отредактируй этот текст:

[вставь текст]

Улучши:
- Ясность (убери лишние слова)
- Энергию (сделай динамичнее)
- Структуру (логичный порядок)

Сохрани мой стиль и голос. Не меняй факты.
Покажи изменённую версию и кратко объясни ключевые правки.
```

### Написать в чужом стиле

```
Напиши [тип текста] в стиле этого примера:

[вставь образец стиля]

Тема: [тема]
Объём: [примерно как в образце]

Сохрани: ритм, длину предложений, характерные приёмы автора.
```

## Создание контента

### Пост для социальных сетей

```
Напиши пост для [Instagram/ВКонтакте/LinkedIn/Telegram] о [тема].

Мой бизнес/проект: [кратко о тебе]
Аудитория: [кто читает]
Цель поста: [информировать/продать/вовлечь/развлечь]
Тон: [как ты обычно пишешь]

Формат:
- Зацепляющее начало (первые 2 строки — самые важные)
- Основная мысль
- Призыв к действию
- [нужны ли хэштеги? если да — сколько]

Объём: [короткий до 150 слов / средний 150-300 / длинный 300+]
```

### Серия постов

```
Создай контент-план на [количество] постов по теме «[тема]».

Для каждого поста укажи:
1. Тема и угол подачи
2. Ключевая мысль
3. Призыв к действию
4. Тип контента (текст/вопрос/история/факт/список)

Аудитория: [кто читает]
Цель серии: [что должны узнать/сделать/почувствовать читатели]
```

### Email или письмо

```
Напиши письмо [кому — клиенту/коллеге/партнёру] с целью [цель письма].

Контекст: [что произошло / предыстория]
Тон: [деловой/тёплый/официальный]
Ключевые моменты, которые нужно включить:
- [пункт 1]
- [пункт 2]

Длина: [короткое до 100 слов / среднее / подробное]
Начни с [обращения] и заверши [подписью или призывом к действию].
```

## Анализ и исследования

### Проанализировать документ

```
Проанализируй этот документ:

[вставь текст или прикрепи файл]

Мне нужно понять:
1. Ключевые идеи (топ-5)
2. Главные риски или проблемы
3. Рекомендации по [конкретный вопрос]

Формат: структурированный список с пояснениями.
Язык: простой, без лишнего жаргона.
```

### Сравнить варианты

```
Сравни эти [N] варианта по ключевым критериям:

Вариант 1: [описание]
Вариант 2: [описание]
[Вариант 3: описание]

Критерии для сравнения:
- [критерий 1 — например, стоимость]
- [критерий 2 — например, скорость внедрения]
- [критерий 3 — например, риски]

Моя ситуация: [контекст, который важен для выбора]
В конце — дай чёткую рекомендацию с обоснованием.
```

### Найти проблемы в тексте / плане

```
Сыграй роль строгого критика. Найди слабые места в этом [тексте/плане/стратегии]:

[вставь материал]

Ищи:
- Логические противоречия
- Пропущенные риски
- Слабые аргументы
- Непроверенные допущения

Будь честен, даже если ответ неприятен. Предложи, как исправить каждую проблему.
```

## Обучение и объяснения

### Объяснить сложную тему

```
Объясни [тема] так, как будто я [уровень: школьник / человек без технического образования / эксперт в другой области].

Используй:
- Простые слова
- Аналогии из повседневной жизни
- Конкретные примеры

Не используй: [список терминов или жаргона, который нужно избегать]

В конце задай мне 2-3 вопроса, чтобы проверить, что я понял.
```

### Составить план обучения

```
Составь пошаговый план изучения [тема/навык] для [кто я — новичок/специалист из другой области].

Цель: [чего хочу достичь]
Время: [сколько часов в неделю готов тратить]
Срок: [за сколько месяцев хочу освоить]

Для каждого шага укажи:
- Что изучаю
- Как практикую (конкретное упражнение)
- Как понять, что освоил

Начни с самого важного, а не с самого простого.
```

### Квиз для самопроверки

```
Составь [количество] вопросов для самопроверки по теме «[тема]».

Уровень сложности: [начальный/средний/продвинутый]
Формат вопросов: [с вариантами ответов / открытые / практические кейсы]

После каждого вопроса — правильный ответ с кратким объяснением.
```

## Бизнес и работа

### Подготовка к переговорам

```
Помоги подготовиться к переговорам с [кем].

Моя цель: [что хочу получить]
Их вероятная цель: [что хотят они]
Мои сильные стороны в этих переговорах: [перечисли]
Мои слабые стороны: [перечисли]

Подготовь:
1. Ключевые аргументы в мою пользу
2. Возможные возражения и мои ответы на них
3. BATNA (лучшая альтернатива, если договориться не получится)
4. Фразы-открывашки для начала разговора
```

### Написать резюме или питч

```
Напиши [резюме/питч/bio] для [контекст: LinkedIn / презентация инвесторам / конференция].

Мой опыт: [ключевые достижения, не полная биография]
Что хочу донести: [главная мысль о себе или проекте]
Аудитория: [кто будет читать]
Объём: [количество слов или символов]

Тон: [уверенный/скромный/экспертный/дружелюбный]
Акцент на: [результаты/процесс/ценности/цифры]
```

### Брейнсторм идей

```
Проведи мозговой штурм на тему «[тема]».

Контекст: [краткое описание проекта или задачи]
Ограничения: [бюджет, время, ресурсы, что нельзя делать]
Критерии хорошей идеи: [что важно]

Сгенерируй [количество] идей. Включи:
- 5 очевидных (проверенных) идей
- 5 нестандартных
- 2 радикальных (даже если кажутся невозможными)

Не фильтруй — сначала список, оценка потом.
```

## Личная продуктивность

### Разобрать сложную задачу

```
У меня есть задача: [опиши задачу]

Я застрял на: [где именно затруднение]
Моя цель: [конечный результат]
Ресурсы: [что есть — время, деньги, люди, инструменты]

Разбей задачу на конкретные шаги. Для первого шага — дай детальную инструкцию, что именно делать прямо сейчас.
```

### Принять решение

```
Помоги принять решение: [опиши дилемму]

Варианты:
А) [вариант А]
Б) [вариант Б]

Что важно для меня: [ценности, приоритеты, ограничения]
Что меня останавливает: [страхи, сомнения]

Задай мне 3 уточняющих вопроса, которые помогут прояснить решение. Потом — дай своё мнение.
```

### Написать план дня / недели

```
Помоги составить план на [день/неделю].

Главные задачи: [список, максимум 5]
Дедлайны: [что срочно]
Энергия: [когда я лучше работаю — утром/вечером]
Встречи и обязательства: [фиксированные блоки]

Расставь приоритеты. Скажи, что можно делегировать или отложить.
Оставь буфер на неожиданное.
```

## Системные промпты (для настройки ИИ)

### Персональный ассистент

```
Ты — мой личный ассистент по имени [имя].

Обо мне:
- Имя: [твоё имя]
- Работа: [чем занимаешься]
- Главные проекты: [перечисли]
- Стиль общения: [как тебе комфортно]

Твои правила:
- Всегда отвечай кратко, если не прошу подробностей
- Если задача неясна — задай один уточняющий вопрос
- Предлагай лучший вариант, не перечисляй все возможные
- Если я ошибаюсь — скажи прямо
```

### Экспертный консультант

```
Ты — опытный [профессия: маркетолог/юрист/финансовый консультант/HR] с 15+ годами практики.

Ты консультируешь малый и средний бизнес. Твой стиль:
- Говоришь прямо, без лишних оговорок
- Даёшь конкретные рекомендации, а не «зависит от ситуации»
- Предупреждаешь о рисках, но не пугаешь
- Объясняешь сложное простым языком

Мой бизнес: [краткое описание]
Моя главная проблема сейчас: [проблема]
```

## Комбо-промпты (продвинутый уровень)

### Итерация до идеала

```
Напиши первый вариант [текста/плана/решения] по этому запросу:
[запрос]

После каждого варианта я буду давать короткую обратную связь.
Ты дорабатываешь на основе фидбека. Максимум 3 итерации.
Начни.
```

### Дьявольский адвокат

```
Я собираюсь [решение/план/идея].

Сыграй роль самого жёсткого критика. Найди всё, что может пойти не так. Не смягчай — говори прямо.

После критики — предложи, как сделать план устойчивее к этим рискам.
```

## Наставники о шаблонах

> *«Шаблон — это не костыль. Это стандарт. Лучшие врачи, пилоты и программисты работают по чеклистам. Не потому что не умеют думать. Потому что знают: стандарт надёжнее импровизации.»*
> **— Мясник**

> *«Шаблон даёт форму. Но содержание — всегда твоё. Заполняя [квадратные скобки], ты переводишь мысль в действие. Это и есть магия: структура освобождает, не ограничивает.»*
> **— Странник**

> *«Начни с одного шаблона — того, что решает твою главную задачу прямо сейчас. Используй его три раза подряд. Потом адаптируй под себя. Постепенно у тебя появится своя библиотека промптов. Это и есть мастерство.»*
> **— Ментор**
