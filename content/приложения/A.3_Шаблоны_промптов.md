# Приложение A.3: Шаблоны промптов — Книга Заклинаний Квестора

*«У каждого великого мага есть гримуар — книга заклинаний, собранная за годы практики. Ты не обязан изобретать каждое заклинание с нуля. Бери проверенные формулы, адаптируй под себя — и твой Джин будет творить чудеса.»*

---

## 📜 Системное сообщение

> *Игрок, ты получил доступ к Гримуару.*
> *Здесь собраны боевые заклинания — шаблоны промптов,*
> *проверенные тысячами Квесторов на всех уровнях.*
> *Каждый шаблон — готовая формула.*
> *Подставь свои данные — и Джин выполнит задачу.*
> *Но помни: шаблон — это начало, а не конец.*
> *Лучшие заклинания рождаются, когда ты делаешь шаблон своим.*

---

## Как пользоваться Гримуаром

Каждый шаблон содержит:
- **🎯 Цель** — для какой задачи подходит
- **📋 Шаблон** — готовая формула с переменными в `[квадратных скобках]`
- **💡 Пример** — как выглядит заклинание в действии
- **⚡ Совет Наставника** — как усилить эффект

Переменные в `[квадратных скобках]` — замени на свои данные. Всё остальное — оставь как есть.

> **🧙 Странник:**
> «Шаблон — это не клетка, а трамплин. Мастер начинает с шаблона, но быстро перерастает его. Однако даже самый опытный маг возвращается к базовым формулам, когда задача новая. Не стыдись пользоваться шаблонами — стыдись не пользоваться ничем.»

## ⚔️ Уровень 1: Базовые заклинания

### 🔮 Шаблон «Задай роль»

**🎯 Цель:** Превратить Джина из универсального ассистента в узкого специалиста.

**📋 Шаблон:**
```
Ты — [роль: опытный маркетолог / детский психолог / шеф-повар].
Твоя задача — [что нужно сделать].
Целевая аудитория — [для кого результат].
Формат ответа — [список / таблица / пошаговая инструкция / эссе].
```

**💡 Пример:**
```
Ты — опытный диетолог с 15-летним стажем.
Твоя задача — составить план питания на неделю.
Целевая аудитория — мужчина 40 лет, офисная работа, хочет сбросить 5 кг.
Формат ответа — таблица по дням с указанием калорий.
```

**⚡ Совет:** Чем конкретнее роль, тем точнее результат. «Маркетолог» — слабо. «Маркетолог в B2B SaaS с фокусом на LinkedIn» — мощно.

---

### 🔮 Шаблон «Цепочка рассуждений»

**🎯 Цель:** Заставить Джина думать пошагово, а не выдавать первый попавшийся ответ.

**📋 Шаблон:**
```
[Опиши задачу].

Прежде чем отвечать:
1. Проанализируй ключевые факторы
2. Рассмотри минимум 3 варианта решения
3. Для каждого варианта укажи плюсы и минусы
4. Выбери лучший и объясни почему
```

**💡 Пример:**
```
Я хочу начать онлайн-бизнес с бюджетом 500 долларов.
У меня есть навыки копирайтинга и базовое знание дизайна.

Прежде чем отвечать:
1. Проанализируй мои навыки и бюджет
2. Рассмотри минимум 3 варианта бизнеса
3. Для каждого варианта укажи плюсы и минусы
4. Выбери лучший и объясни почему
```

> **💀 Мясник:**
> «90% людей пишут Джину: "Какой бизнес открыть?" И получают размытую кашу. Добавь одну строчку — "Рассмотри 3 варианта с плюсами и минусами" — и ответ становится в десять раз полезнее. Одна строчка! Ты же не поленишься написать одну строчку?»

---

### 🔮 Шаблон «Формат вывода»

**🎯 Цель:** Получить ответ в нужной структуре, а не «стену текста».

**📋 Шаблон:**
```
[Задача].

Ответь в формате:
- Заголовок: [тема]
- Резюме: 2-3 предложения
- Основные пункты: нумерованный список (5-7 пунктов)
- Вывод: 1 предложение
- Следующий шаг: конкретное действие
```

**⚡ Совет:** Джин буквально выполняет инструкции по формату. Хочешь таблицу — попроси таблицу. Хочешь маркированный список — попроси маркированный список. Не нравится длина — скажи «не более 200 слов».

## 🔍 Уровень 2: Заклинания Исследователя

### 🔮 Шаблон «Глубокое исследование»

**🎯 Цель:** Разобраться в незнакомой теме за один сеанс.

**📋 Шаблон:**
```
Я хочу глубоко разобраться в теме: [тема].
Мой текущий уровень знаний: [новичок / средний / продвинутый].

Сделай следующее:
1. Объясни суть темы простым языком (как для 12-летнего)
2. Дай 5 ключевых концепций, которые необходимо понять
3. Укажи 3 распространённых заблуждения
4. Составь план изучения на [срок: неделю / месяц]
5. Порекомендуй 3 лучших источника для дальнейшего изучения
```

**💡 Пример:**
```
Я хочу глубоко разобраться в теме: блокчейн и криптовалюты.
Мой текущий уровень знаний: новичок.

Сделай следующее:
1. Объясни суть темы простым языком (как для 12-летнего)
2. Дай 5 ключевых концепций, которые необходимо понять
3. Укажи 3 распространённых заблуждения
4. Составь план изучения на месяц
5. Порекомендуй 3 лучших источника для дальнейшего изучения
```

---

### 🔮 Шаблон «Второе мнение»

**🎯 Цель:** Проверить информацию или решение, получив критический анализ.

**📋 Шаблон:**
```
Вот утверждение / решение / план: [вставь текст].

Выступи в роли критика-скептика:
1. Что здесь правильно?
2. Что может быть ошибкой или преувеличением?
3. Какие аргументы ПРОТИВ этой позиции?
4. Что автор мог упустить?
5. Твой вердикт: насколько это надёжно (от 1 до 10)?
```

> **🧭 Ментор:**
> «Этот шаблон — один из самых недооценённых. Люди используют AI, чтобы подтвердить то, во что уже верят. Мастер использует AI, чтобы найти дыры в своих убеждениях. Привыкни проверять каждое важное решение через шаблон "Второе мнение". Это спасёт тебя от дорогих ошибок.»

## 🏗️ Уровень 3: Заклинания Строителя

### 🔮 Шаблон «Структура проекта»

**🎯 Цель:** Превратить расплывчатую идею в план действий.

**📋 Шаблон:**
```
Я хочу создать: [описание проекта].
Цель проекта: [чего хочу достичь].
Мои ресурсы: [время, деньги, навыки].
Ограничения: [дедлайны, бюджет, технические ограничения].

Создай детальный план:
1. Разбей на фазы (3-5 фаз)
2. Для каждой фазы: задачи, сроки, ожидаемый результат
3. Укажи риски и как их минимизировать
4. Определи критерии успеха для каждой фазы
5. Что можно сделать прямо сейчас (первые 30 минут)?
```

---

### 🔮 Шаблон «Итеративное улучшение»

**🎯 Цель:** Улучшить текст, код, план — любой артефакт — через серию уточнений.

**📋 Шаблон:**
```
Вот мой [текст / код / план]: [вставь].

Улучши его по следующим критериям:
1. [Критерий 1: ясность / краткость / убедительность]
2. [Критерий 2: структура / логика / стиль]
3. [Критерий 3: целевая аудитория / тон / формат]

Покажи улучшенную версию и объясни, что именно изменил и почему.
```

**⚡ Совет:** Это заклинание можно применять многократно. Получил результат — снова прогони через этот шаблон с новыми критериями. Три-четыре итерации превращают черновик в шедевр.

## ⚙️ Уровни 4–5: Заклинания Мастера

### 🔮 Шаблон «Системный промпт для Custom GPT»

**🎯 Цель:** Создать персонализированного ассистента с постоянным характером и компетенциями.

**📋 Шаблон:**
```
# Роль
Ты — [имя и роль]. [1-2 предложения о характере и стиле общения].

# Компетенции
- [Область знаний 1]
- [Область знаний 2]
- [Область знаний 3]

# Правила поведения
1. Всегда [ключевое правило — например, "давай конкретные примеры"]
2. Никогда не [антипаттерн — например, "не используй общие фразы"]
3. Если не знаешь ответ — [что делать — например, "честно скажи об этом"]

# Формат ответов
- Длина: [короткие / средние / развёрнутые]
- Стиль: [формальный / дружелюбный / прямой]
- Структура: [списки / абзацы / пошаговые инструкции]
```

> **💀 Мясник:**
> «Системный промпт — это ДНК твоего ассистента. Напортачил — получишь мутанта. Потратил 20 минут на хороший промпт — получишь машину, которая будет работать на тебя месяцами. Что выберешь: 20 минут сейчас или часы разочарования потом?»

---

### 🔮 Шаблон «Автоматизация задачи»

**🎯 Цель:** Описать рутинную задачу так, чтобы AI мог выполнять её регулярно.

**📋 Шаблон:**
```
# Задача
[Название задачи]

# Вход
Я буду предоставлять: [тип данных — текст / таблицу / список].

# Обработка
Для каждого элемента:
1. [Шаг 1]
2. [Шаг 2]
3. [Шаг 3]

# Выход
Результат в формате: [таблица / JSON / маркированный список].

# Пример
Вход: [пример входных данных]
Ожидаемый выход: [пример результата]
```

## 🤖 Уровни 8–10: Заклинания Архитектора

**📋 Шаблон:**

```
Напиши для меня оптимальный промпт, который:

2. Содержит весь необходимый контекст
3. Определяет формат вывода

```

> **🧙 Странник:**

## 🏆 Универсальные боевые заклинания

Эти шаблоны работают в любой ситуации — от первого уровня до последнего.

### Формула РАКЕТА

Запомни аббревиатуру — **Р.А.К.Е.Т.А.** — и ни один промпт не пропадёт:

| Буква | Элемент | Вопрос |
|-------|---------|--------|
| **Р** | Роль | Кем должен быть Джин? |
| **А** | Аудитория | Для кого результат? |
| **К** | Контекст | Какая предыстория и ситуация? |
| **Е** | Единица результата | Что конкретно нужно получить? |
| **Т** | Тон и стиль | Как это должно звучать? |
| **А** | Ацкие ограничения | Чего делать нельзя / лимиты? |

**💡 Пример по формуле РАКЕТА:**
```
[Р] Ты — опытный HR-менеджер в технологической компании.
[А] Пишешь для кандидата, который нервничает перед собеседованием.
[К] Кандидат — junior-разработчик, первое собеседование в жизни.
[Е] Составь список из 10 типичных вопросов на собеседовании с образцами ответов.
[Т] Дружелюбный, поддерживающий тон. Без канцелярита.
[А] Не более 500 слов. Без общих фраз типа "будьте собой".
```

## 📌 Памятка на стену

Пять правил хорошего промпта, которые ты должен помнить всегда:

1. **Будь конкретен.** «Напиши текст» → «Напиши пост для LinkedIn на 150 слов о пользе утренних прогулок для продуктивности»
2. **Задай роль.** Джин без роли — генерал без армии. Назначь специалиста.
3. **Покажи формат.** Не надейся, что Джин угадает. Скажи: таблица, список, абзац.
4. **Давай примеры.** Один пример стоит тысячи слов объяснений.
5. **Итерируй.** Первый ответ — черновик. Второй — лучше. Третий — отлично. Не сдавайся после первого.

> **🧭 Ментор:**
> «Эти шаблоны — твоя стартовая площадка. Со временем ты начнёшь писать промпты интуитивно, как музыкант, который больше не думает о нотах. Но до того момента — пользуйся Гримуаром. Каждый профессионал начинал с шаблонов. Каждый мастер однажды перерос их. Но ни один мастер не жалел, что начал именно так.»
