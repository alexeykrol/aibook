## 2. Дополнительные документы

### 2.1 Управление проектом (`meta/`)

1. `meta/PROJECT_SNAPSHOT.md` — быстрый статус проекта
2. `meta/BACKLOG.md` — фазы и задачи
3. `meta/PROCESS.md` — рабочий процесс
4. `meta/BOOK_STRUCTURE.md` — концептуальная структура книги
5. `meta/notes/` — заметки

### 2.2 Шаблоны (`templates/`)

1. `templates/level_template.md`
2. `templates/exercise_template.md`
3. `templates/case_template.md`

### 2.3 Черновики (`drafts/`)

1. `drafts/Исходные тексты/` — исходные материалы
2. `drafts/Доп. файлы/` — дополнительные заготовки
3. `drafts/Идеи книги/` — идеи и компоновка
4. `drafts/master/` — сборка мастер-версии
5. `drafts/episodes/` — материалы для эпизодов/рассылки

### 2.4 Архив (`archive/`)

1. `archive/v1/` — архивные материалы и промо-фрагменты

### 2.5 Команды и системные файлы

1. `.claude/commands/` — вспомогательные slash-команды
2. `CLAUDE.md` — правила контекста агента
3. `CONTRIBUTING.md` — правила участия
4. `CHANGELOG.md` и `CHANGELOG_RU.md` — история изменений
5. `VERSION` — версия проекта
