# Project Request

> Тип документа: `project input`
> Дата: `2026-03-18`

## Project Name

AI Quest: Now You Can!

## What do you want to build?

Образовательную книгу-квест в формате ЛитРПГ об освоении искусственного интеллекта.

Книга = квест-игра: 10 уровней мастерства, боссы (страхи читателя), квесты (практические задания), награды (новые способности).

Конечный результат: готовая рукопись на русском языке, готовая к редактуре и публикации.

## Who is this for?

- Возраст: 20-70 лет
- Профессия: любая (не обязательно технари)
- Мотивация: хотят использовать AI, но не знают как начать
- Боль: чувствуют что "отстают", видят возможности но не могут ими воспользоваться

## What problem does it solve?

Люди видят революцию AI, но не могут в неё войти. Существующие материалы либо слишком технические, либо поверхностные. Эта книга даёт пошаговый путь от "ничего не умею" до "AI — мой главный инструмент" через геймифицированный формат.

## Key Features

1. 10 уровней мастерства — от базовых промптов до AI-агентов
2. ЛитРПГ-формат — боссы, квесты, награды, три наставника-персонажа
3. Практические задания в каждом уровне — читатель делает, а не только читает
4. Примеры из реальной жизни разных профессий
5. Три голоса наставников: Мясник (прямой), Странник (философский), Ментор (системный)

## Technical Preferences

- Language: Русский (основной), English (перевод — позже)
- Format: Markdown файлы в структуре content/
- Templates: templates/level_template.md, exercise_template.md, case_template.md
- Style reference: content/0_введение/1_Введение.md
